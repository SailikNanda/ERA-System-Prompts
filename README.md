1. **Browse** the folders to find the mood that matches your vibe

5. **Enjoy** your personalized interaction experience!

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/SailikNanda/ERA-System-Prompts.git
cd ERA-System-Prompts
```

### Choose Your Mood

```bash
# Browse available moods
ls -la

# Open your favorite mood directory
cd 01-best-friend
```

### Apply to ERA AI Agent

1. Copy the prompt content from your chosen mood folder
2. Paste it into your ERA AI Agent's system prompt configuration
3. Start chatting with your new personality!
